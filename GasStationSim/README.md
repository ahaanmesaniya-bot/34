# Gas Station Simulator — पहला Playable Version (v0.1)

## इसमें क्या है
- फर्स्ट-पर्सन 3D गेम (Godot 4.3 इंजन)
- 3 फ्यूल पंप + 2 शॉप शेल्फ़ — पास जाओ, "HOLD TO WORK" बटन दबाए रखो, पैसे कमाओ
- मोबाइल टच कंट्रोल: बाईं तरफ़ जॉयस्टिक (चलने के लिए), स्क्रीन पर उंगली घुमाकर कैमरा घुमेगा
- Low-poly / stylized ग्राफ़िक्स (procedurally generated — कोई बाहरी 3D मॉडल फ़ाइल नहीं चाहिए)

## बिना लैपटॉप के APK कैसे बनाएं (फ़ोन से)

1. फ़ोन में **github.com** पर जाकर फ्री अकाउंट बनाएं (या GitHub ऐप इंस्टॉल करें)
2. एक नया **public repository** बनाएं (नाम जो चाहें रखें)
3. इस पूरे zip को extract करके उसके अंदर की सारी फ़ाइलें/फ़ोल्डर उस repository में **upload** करें (GitHub वेबसाइट पर "Add file → Upload files" से हो जाता है, फ़ोल्डर स्ट्रक्चर बना रहना चाहिए — `.github/workflows/build-android.yml` वाला पाथ सही रहना ज़रूरी है)
4. Upload के बाद repository के **"Actions"** टैब में जाएं — "Build Android APK" वर्कफ़्लो अपने आप चलनी शुरू हो जाएगी (कुछ मिनट लगेंगे)
5. वर्कफ़्लो पूरी होने पर उसी पेज पर नीचे **"Artifacts"** में `gas-station-simulator-apk` दिखेगा — उसे डाउनलोड करें (zip के अंदर APK होगी)
6. फ़ोन में APK इंस्टॉल करें (शायद "Unknown apps install" की परमिशन देनी पड़े) — और गेम टेस्ट करें!

अगर Action fail हो जाए, तो लॉग में जो error आए वो मुझे भेज दीजिए, मैं फ़िक्स कर दूंगा।
